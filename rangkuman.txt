1. VERSION CONTROL SYSTEM (VCS)
- Definisi: Praktik pelacakan dan pengelolaan perubahan pada file dari waktu ke waktu.
- Jenis-jenis VCS:
  a. VCS Lokal: Menyimpan basis data perubahan di komputer lokal (contoh: RCS).
  b. VCS Terpusat (Client-Server): Terpusat di satu server utama (contoh: CVS, Subversion).
  c. VCS Terdistribusi (Peer-to-Peer): Setiap pengguna memiliki salinan penuh riwayat reposit


  2. DASAR-DASAR GIT
- Status File pada Git:
  a. Untracked: File baru yang belum pernah dilacak oleh Git.
  b. Staged: File yang sudah ditandai dan masuk ke staging area.
  c. Unmodified: File yang sudah di-commit dan belum mengalami editan baru.
  d. Modified: File terlacak yang mengalami perubahan isi/kode.

  2. DASAR-DASAR GIT
- Status File pada Git:
  a. Untracked: File baru yang belum pernah dilacak oleh Git.
  b. Staged: File yang sudah ditandai dan masuk ke staging area.
  c. Unmodified: File yang sudah di-commit dan belum mengalami editan baru.
  d. Modified: File terlacak yang mengalami perubahan isi/kode.

- Perintah Dasar Git:
  * git init                 : Menginisialisasi folder menjadi repositori Git lokal.
  * git config --global ...  : Mengatur konfigurasi pengguna (nama, email, editor, branch default).
  * git status               : Memeriksa status file pada direktori kerja dan staging area.
  * git add <file> / .       : Menambahkan file ke staging area.
  * git commit -m "<pesan>"  : Menyimpan snapshot riwayat perubahan dari staging area.
  * git reset HEAD~1         : Membatalkan commit terakhir di lokal.
  * git log / --oneline      : Melihat riwayat commit yang pernah dibuat.

  3. PENGGUNAAN REMOTE REPOSITORY & GITHUB
- GitHub adalah layanan cloud berbasis web untuk meng-hosting repositori Git.
- File README: Berkas pembuka utama pada repositori untuk memuat informasi, cara penggunaan, dan dokumentasi proyek.

- Perintah Remote & Sinkronisasi:
  * git branch -M main       : Mengubah nama cabang utama yang aktif menjadi 'main'.
  * git remote add origin <URL> : Menghubungkan repositori lokal ke server remote GitHub.
  * git push -u origin main  : Mengunggah riwayat commit lokal ke remote repository di GitHub.
  * git clone <URL>          : Mengunduh/menyalin repositori jarak jauh ke folder lokal.
  * git fetch <remote>       : Mengambil data terbaru dari remote tanpa langsung menggabungkannya.
  * git pull                 : Mengambil sekaligus menggabungkan perubahan dari remote ke branch lokal.

  4. SINTAKS DASAR MARKDOWN (.md)
- Heading (Judul): Menggunakan simbol pagar `#` (1 sampai 6 tanda pagar untuk menentukan tingkat ukuran).
- Gaya Teks:
  * Tebal   : **teks tebal**
  * Miring  : *teks miring*
  * Coret   : ~~teks dicoret~~
- Daftar (List):
  * Ordered List   : Menggunakan angka urut diikuti titik (contoh: `1. `, `2. `).
  * Unordered List : Menggunakan tanda hubung (`- `) atau simbol asteris (`* `).
- Tautan & Gambar:
  * Link   : [Nama Link](https://alamat-url.com)
  * Gambar : ![Teks Alternatif](https://alamat-gambar.jpg)
- Tabel: Menggunakan garis vertikal `|` sebagai pembatas kolom dan strip `-` untuk pemisah header.
- Blok Kode (Code Block): Menggunakan tiga backtick (```bahasa ... ```) untuk menampilkan potongan baris kode.
