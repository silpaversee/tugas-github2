# Rangkuman Materi Pelatihan Git, GitHub & Markdown

Repositori ini dibuat khusus untuk memuat rangkuman materi pembelajaran dari pengenalan *Version Control System*, dasar-dasar Git, alur kerja GitHub, hingga penulisan format Markdown.

## 📌 Rincian Tugas
- **Nama Berkas:** `file.txt` (atau `rangkuman.txt`)
- **Riwayat Pengerjaan:** Minimal 3 *commit* bertahap beserta pesan deskriptif.

## 📖 Ringkasan Pokok Pembahasan
1. **Version Control System (VCS):** Pengenalan jenis VCS (Lokal, Terpusat, dan Terdistribusi).
2. **Git Dasar:** Status berkas (*untracked*, *staged*, *unmodified*, *modified*), inisialisasi repositori, dan perintah commit.
3. **GitHub & Remote:** Sinkronisasi repositori lokal ke server jarak jauh (*remote*), branching `main`, dan proses `push`.
4. **Sintaks Markdown:** Format penulisan heading, penekanan teks (*bold*, *italic*, *strikethrough*), pembuatan list, link, tabel, dan blok kode.
